# 🚀 Lunar Lander

A retro 2D Lunar Lander game built with **Phaser 3**, **TypeScript**, and **Vite**.

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
